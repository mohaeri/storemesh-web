# StoreMesh Web

RTL operational dashboard for receiving, inventory, tasks, print jobs, quality control, and batch traceability.

Run directly with any static HTTP server, or build the included container. The browser connects to `http://localhost:3000` by default; set `localStorage.api` to another site API URL when needed.

Management and operational web application for site-scoped dashboards, configuration, exceptions, traceability, and reporting.

The web client consumes only versioned contracts from `storemesh-contracts`.
